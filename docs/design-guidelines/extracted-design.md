# RecallRoute visual direction

## Reference extraction

The supplied logo is a soft mint rounded square containing a dark forest battery, circular routing arrows, and a shield alert. Its strongest cues are safety, circular return flow, and calm operational clarity.

## Design system

- Palette: ink `#073f34`, deep `#062e28`, mint `#c8f7db`, signal mint `#79efb1`, paper `#f7fbf8`, warning `#f2a93b`, danger `#d95b52`.
- Typography: editorial sans-serif for display and a compact monospace for IDs, states, and provenance.
- Shape: restrained 18–28px radii, pill statuses, thin dark-green rules, and large breathing room.
- Layout: public explainer uses a circular route motif; the console uses a horizontal checkpoint rail and a two-column dossier/workbench layout. Do not reuse PermitOS's dark three-rail control plane.
- Components: flat paper cards, prominent numbered checkpoints, source receipts, route outcome card, and accessible high-contrast buttons.
- Motion: short route-progress sweep and subtle status pulse; disable under reduced-motion.
- Accessibility: logo text is not relied upon for meaning, status always includes text, focus rings are visible, and mint is never used as low-contrast body text.
